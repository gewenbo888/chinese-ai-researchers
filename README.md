# Chinese AI Researchers

A bilingual reference of notable Chinese researchers shaping modern AI.

[![Live Demo](https://img.shields.io/badge/demo-chinese--ai--researchers.vercel.app-a8322c)](https://chinese-ai-researchers.vercel.app)

## Overview

A Next.js site profiling Chinese AI researchers — academics and industry leaders — with biographies, affiliations, and notable contributions, presented in English and Chinese side by side.

## Design & Tech

- **Stack:** Next.js, React, Tailwind CSS
- **Deployment:** Vercel

## Getting Started

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).
